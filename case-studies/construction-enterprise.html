The Full Story

A comprehensive construction company management system built with React and Express. Features include project management, task tracking, employee management, attendance, submissions, reports, checklists, billing/invoicing, real-time updates via Socket.io, PDF generation with PDFKit, Excel export with ExcelJS, and role-based access control with JWT authentication.
